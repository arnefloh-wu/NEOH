# GitHub Pages

`index.html` ist das Dashboard, erzeugt von `dashboard_at.py` im
Projektstammverzeichnis. Nicht von Hand bearbeiten — Änderungen gehen beim
nächsten Lauf verloren.

**Einmalig zu aktivieren:** Repository → Settings → Pages → Source
„Deploy from a branch", Branch `main`, Ordner `/docs`, Save. Die Seite steht
danach unter `https://arnefloh-wu.github.io/NEOH/`.

**Das Repository ist öffentlich**, die Pages-Seite wäre es damit auch. Die
Seite enthält keine Falldaten, sondern nur aggregierte Zellen mit mindestens
zwölf Fällen — personenbezogene Daten werden also nicht veröffentlicht. Ob die
Ergebnisse selbst öffentlich stehen sollen, bevor sie mit NEOH abgestimmt sind,
ist eine andere Frage und vor dem Aktivieren zu klären.
